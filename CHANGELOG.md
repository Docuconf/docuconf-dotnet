[release-please](https://github.com/googleapis/release-please) from Conventional Commit messages; see
[CONTRIBUTING.md](CONTRIBUTING.md).

## 0.1.0-alpha.1

First version: typed configuration contracts for the .NET Options pattern, implementing spec `v1alpha1`.

### Features

* Declarations from options classes and their DataAnnotations, plus docuconf attributes for secrets, URL schemes,
  file inputs and `[JsonVar]` structured values.
* Startup validation of environment variables, `appsettings*.json` and file inputs (TLS key pairs, CA bundles,
  keystores, JSON config files, licence files) that reports every problem at once with stable error codes;
  `IOptionsMonitor` reload notifications.
* Contract export (`docuconf export`), including config-file overlays and `itemMin`/`itemMax` on integer lists.
* Contract-first mode and the shared conformance runner.
* The `orders` example and the `Billing.Api` sample; NuGet packaging with symbols and SourceLink.
